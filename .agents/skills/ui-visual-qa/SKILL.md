# ui-visual-qa

- Run the repository’s available build and checks. Exercise the changed route with normal, long and missing data as relevant.
- Capture screenshots at mobile, tablet and desktop. Check horizontal overflow, headings, contrast, focus, CTA visibility and gallery controls.
- For scroll scenes, sample 0%, 33%, 66% and 100%, then scroll back. Repeat with reduced motion and WebGL disabled when relevant.
- Report exact commands, observed results and uncovered cases. Verify actual navigation and forms, alongside screenshots.
