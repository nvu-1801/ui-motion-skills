# Authoring review

- Capability has a specific trigger, output and boundary; negative tasks do not activate it.
- Existing skills were considered before adding another overlapping name.
- Scripts have a real repeatability/correctness benefit and observed validation.
- References are reachable inside the installed package and loaded only on demand.
- Source provenance/license recorded before redistribution; credentials and source-project business values excluded.
- Compare task outcomes and costs with stable model/settings; missing telemetry remains null/unavailable.
- Package installation/update and meaningful behavioral fixtures pass; record checks not run.

Keep automatic discovery enabled unless the user requests explicit-only invocation. Don't force a fixed number of skills when a task needs more, or open all skills as a default.
