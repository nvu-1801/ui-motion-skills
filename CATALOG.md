# Skill catalog

Select a small initial set with `python scripts/select-skills.py <task-kind>` or this index, then open only relevant SKILL.md files. Start with 1–3 when sufficient; expand for actual dependencies or failures. References and templates are on demand. Host loading behavior still depends on the agent.

| Skill | Trigger / purpose |
| --- | --- |
| agent-lessons | Preserve a verified reusable bug lesson with reproduction, root cause and regression evidence; retrieve only relevant cases. |
| backend-api-contracts | Design or change HTTP API contracts, including validation, status codes, errors, pagination and safe retry behavior. |
| backend-nextjs | Implement Next.js backend features with App Router Route Handlers, Server Actions and server-only data access. |
| backend-workflow | Implement or review backend features across frameworks while preserving domain rules, authorization and data consistency. |
| bug-reproduction | Diagnose and fix reproducible defects using root-cause evidence and a targeted regression check. |
| business-logic-review | Review domain rules, state transitions, permissions and concurrent side effects against project contracts. |
| code-review | Review a diff for actionable regressions and verify automated review findings before changing code. |
| database-migrations | Plan and validate schema migrations and backfills across old/new app versions with realistic recovery constraints. |
| dependency-security | Assess dependency and lockfile risk, licenses and safe upgrades using the target project ecosystem. |
| github-actions | Create, validate or diagnose GitHub Actions workflows and checks for the exact requested revision. |
| landing-business-rules | Preserve and verify product rules when creating or redesigning a landing page, catalog entry point or lead-generation flow. |
| quality-workflow | Select focused checks and skills for a code change or quality audit; avoid loading unrelated skills. |
| release-deploy | Push authorized changes, follow CI and deploy revisions with explicit health evidence and rollback context. |
| scroll-storytelling | Implement sticky scroll-driven storytelling and chapter reveals with CSS or GSAP ScrollTrigger. |
| security-review | Review changed trust boundaries, authorization and sensitive data paths for concrete exploitable defects. |
| skill-authoring | Create, revise or consolidate reusable agent skills with precise activation and portable resources. |
| skill-evaluation | Evaluate skill activation, actual task outcomes and observed cost without confusing script tests with agent behavior. |
| static-analysis | Configure or interpret lint, type checks, SonarQube and Semgrep without treating scanner output as verified logic correctness. |
| ui-components | Implement responsive web UI components using existing tokens, real product data and accessible interaction states. |
| ui-design | Design polished responsive web interfaces, landing pages and portfolios with deliberate visual hierarchy and reusable design tokens. |
| ui-system-reuse | Find and reuse existing UI components, variants, typography, colors and shared models before introducing new UI code. |
| ui-visual-qa | Verify changed web UI across screen sizes, keyboard use, product workflow and relevant motion fallbacks. |
| ui-workflow | Guide an end-to-end UI design and coding task in an existing repository while preserving product workflows. |
| upstream-skill-audit | Review downloaded skill or tool sources, licensing and execution scope before importing or running them. |
| web-3d-scenes | Implement WebGL or React Three Fiber scenes for web UI, including scroll-driven camera movement and static fallbacks. |
